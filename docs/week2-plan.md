> ✏️ **작성 방법:** 오른쪽 위 연필 ✏️ 아이콘을 누르고 빈칸에 내용을 적은 다음 **Commit changes**를 누르세요.

## 1️⃣ 이 게임을 한 문장으로 소개하기

> 예: 고양이가 떨어지는 생선을 받고 폭탄은 피하며 최대한 오래 버티는 게임

**답:** 10초 전 자신의 행동을 반복하는 분신과 협력하거나 그 행동을 이용해 다양한 퍼즐을 해결하고 탈출하는 2D 시간 퍼즐 게임.

## 2️⃣ 타깃 플레이어

> 이 게임을 누가 할지 적습니다. 아직 못 정했으면 빈칸으로 둡니다.

**답:** 퍼즐이나 전략 게임을 좋아하고, 단순한 조작으로도 창의적인 문제 해결과 새로운 게임 방식을 경험하고 싶은 청소년 및 일반 플레이어.

## 3️⃣ 레퍼런스 게임 (2~3개)

| 🎮 게임 이름 | 🏷️ 장르 | 👀 참고하고 싶은 점 |
|---|---|---|
| The Talos Principle | 3d 퍼즐 | 과거의 행동을 기록하고 재생하여 퍼즐을 해결하는 방식 |
| Braid | 2d퍼즐 | 시간이라는 요소를 이용한 독창적인 퍼즐 설계 |
| The Swapper | 2d퍼즐 | 분신을 활용한 공간적 퍼즐과 협력 구조 |

## 4️⃣ 핵심 요소

> 이 게임에서 가장 중요한 재미 요소는 무엇인가요?

**답:** 자신의 과거 행동이 미래에 영향을 미친다는 독특한 시간 시스템을 활용하여 퍼즐을 해결하는 재미.  
플레이어의 위치와 이동 경로가 10초 동안 기록되며, 이후 분신이 등장해 해당 행동을 반복한다.  
플레이어는 분신이 특정 발판을 밟도록 유도하거나, 분신의 이동 경로를 이용하여 혼자서는 해결할 수 없는 퍼즐을 풀어야 한다.  
게임이 진행될수록 새로운 장애물과 장치가 등장하여, 과거의 자신과 협력하거나 과거의 행동으로 인해 생기는 문제를 해결하게 된다.

## 5️⃣ 스테이지 1 만들어 보기

> 📌 게임 전체가 아니라 **첫 번째 스테이지 하나만** 생각합니다. 스테이지 1을 만들려면 무엇이 필요한지 적어 봅니다.

### 5-1. 스테이지 1에서 일어나는 일

| 구분 | 내 게임에서는 | 예시 |
|---|---|---|
| ▶️ **시작할 때** | 플레이어가 방의 왼쪽에서 시작한다. 방에는 발판 하나와 잠긴 문, 출구가 존재한다. | 플레이어가 화면 아래에 서 있다 |
| 🔄 **플레이 중** | 플레이어가 이동하면 10초 동안 이동 경로가 기록된다. 10초가 지나면 과거의 분신이 나타나 기록된 행동을 반복한다. 분신이 발판을 밟도록 경로를 설계하여 문을 열어야 한다. | 위에서 생선과 폭탄이 떨어진다 |
| 🏆 **클리어 조건** | 과거의 분신이 발판을 밟고 있는 동안 현재 플레이어가 열린 문을 통과하여 출구에 도착하면 성공한다. | 생선 10개를 받으면 성공 |
| 💥 **실패 조건** | 분신의 행동을 잘못 설계해 문을 통과하지 못할 수 있다. 시간 제한이나 별도의 게임 오버는 없으며, R키로 스테이지를 초기화하여 재도전할 수 있다. | 폭탄에 3번 맞으면 실패 |

### 5-2. 스테이지 1에 등장하는 것들

게임 프로그램은 등장하는 것마다 **갖고 있는 정보**와 **하는 행동**으로 이루어집니다. 아래 표가 나중에 내 프로그램의 구조가 됩니다.

| 이름 | 갖고 있는 정보<br>(예: 위치, 목숨) | 하는 행동 또는 규칙<br>(예: 이동, 점프) |
|---|---|---|
| 🧍 **플레이어** | 현재 위치, 이동 속도, 이동 방향 | 키보드 입력에 따라 이동하며 출구에 도착하면 스테이지 클리어 |
| 과거의 분신 | 기록된 위치 정보, 재생 시간, 현재 위치 | 10초 전 플레이어의 이동 경로를 재현하고 발판을 작동시킬 수 있음 |
| 발판 | 위치, 활성화 여부 | 플레이어나 분신이 올라가 있는 동안 문을 열어 줌 |
| 문 | 위치, 열림·닫힘 상태 | 발판이 활성화되면 열리고 비활성화되면 닫힘 |
| 출구 | 위치, 도착 여부 | 실제 플레이어가 도착하면 스테이지 클리어 |
| 벽 | 위치, 충돌 범위 | 플레이어의 이동을 제한하고 이동 경로를 구성함 |
| 시간 시스템 | 경과 시간, 10초간 기록된 위치 데이터 | 플레이어의 이동을 기록하며 10초마다 새로운 분신으로 교체함 |

> 플레이어 외에 몬스터, 퍼즐, 아이템, 장애물 등 스테이지 1에 꼭 필요한 것만 적습니다. 부족하면 같은 모양으로 줄을 더 추가해도 돼요.

### 5-3. 입력 방식

> 사용할 입력 방식의 `[ ]`를 `[x]`로 바꾸고, 어떤 입력이 어떤 동작이 되는지 적습니다.

- [x] ⌨️ 키보드
- [ ] 🖱️ 마우스

| 입력 | 게임 속 동작 |
|---|---|
| 예: 스페이스 키 | 점프 |
| w,a,s,d | 위 왼 밑 오 이동 |
| r | 스테이지 초기화, 다시시작 |
| esc | 일시정지 및 메뉴 열기 |
