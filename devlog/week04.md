## 1️⃣ Gemini에게 보낸 게임 만들기 프롬프트

> **🎮 Gemini로 내 게임 만들기 → 3단계**에서 프롬프트를 복사하면 여기에 자동으로 들어가요.

```text
너는 고등학생과 함께 HTML 웹게임을 만드는 게임 개발자야.
맨 아래 [내 게임 기획서]는 내가 3주차에 정리한 게임 기획서야.
첨부한 이미지는 3주차에 만든 이 게임의 "스테이지 1" 화면 목업이야. 화면 배치, 색, 모양, 점수·버튼 위치는 이 목업을 최대한 따라 해.
이것을 바탕으로 "스테이지 1"을 실제로 플레이할 수 있는 웹게임으로 만들어 줘. Canvas에서 바로 실행해 볼 수 있게 만들어 줘.

[만드는 규칙]
- HTML 파일 하나에 HTML, CSS, JavaScript를 모두 넣어. 외부 이미지·소리 파일이나 라이브러리 없이 브라우저에서 바로 실행되게 해.
- 기획서의 5-1(시작할 때·플레이 중·클리어 조건·실패 조건), 5-2(등장하는 것들), 5-3(입력)을 하나도 빠뜨리지 말고 넣어.
- 화면 시점은 기획서의 화면 시점을 따라. 없으면 목업 이미지의 시점을 따라.
- 캐릭터와 물건은 도형, 이모지, Canvas 그리기로 단순하게 표현해.
- 기획서에 없는 기능(새 캐릭터, 스테이지 2, 상점, 업그레이드 등)은 넣지 마.
- 기획서에 숫자가 없는 것(속도, 시간, 개수 등)은 처음 하는 사람도 할 만한 값으로 정하고, 코드 맨 위에 "설정값"으로 모아 둬.
- 순서: 시작 화면(게임 제목, 조작법, 시작 버튼) → 게임 → 클리어 또는 게임오버 화면(결과, 다시 하기 버튼).
- 화면을 클릭하지 않아도 키보드가 바로 동작하게 하고, 방향키나 스페이스를 눌러도 페이지가 스크롤되지 않게 해.
- 코드 중요한 곳에 한국어 주석을 달아 줘.

[게임을 만든 다음 글로 알려 줘]
1. 기획서 반영 점검표: | 기획서 칸 | 게임에 넣은 방법 | ✅ 넣음 / 🔺 바꿈 / ❌ 못 넣음 |
2. 네가 정한 숫자: 기획서에 없어서 네가 정한 값(속도, 시간, 개수 등)과 코드 속 설정값 이름
3. 조작법
4. 처음 플레이할 때 꼭 확인해 볼 것 3가지

마지막에 "플레이해 보고 고치고 싶은 곳을 하나씩 말해 줘"라고 말해 줘.

[내 게임 기획서]
1. 한 문장 소개: 10초 전 자신의 행동을 반복하는 분신과 협력하거나 그 행동을 이용해 다양한 퍼즐을 해결하고 탈출하는 2D 시간 퍼즐 게임.
2. 타깃 플레이어: 퍼즐이나 전략 게임을 좋아하고, 단순한 조작으로도 창의적인 문제 해결과 새로운 게임 방식을 경험하고 싶은 청소년 및 일반 플레이어.
3. 레퍼런스 게임:
   - The Talos Principle (장르: 3d 퍼즐) → 참고하고 싶은 점: 과거의 행동을 기록하고 재생하여 퍼즐을 해결하는 방식
   - Braid (장르: 2d퍼즐) → 참고하고 싶은 점: 시간이라는 요소를 이용한 독창적인 퍼즐 설계
   - The Swapper (장르: 2d퍼즐) → 참고하고 싶은 점: 분신을 활용한 공간적 퍼즐과 협력 구조
4. 핵심 재미 요소: 자신의 과거 행동이 미래에 영향을 미친다는 독특한 시간 시스템을 활용하여 퍼즐을 해결하는 재미.
5-1. 스테이지 1에서 일어나는 일:
   - 시작할 때: 플레이어가 방의 왼쪽에서 시작한다. 방에는 발판 하나와 잠긴 문, 출구가 존재한다.
   - 플레이 중: 플레이어가 이동하면 10초 동안 이동 경로가 기록된다. 10초가 지나면 과거의 분신이 나타나 기록된 행동을 반복한다. 분신이 발판을 밟도록 경로를 설계하여 문을 열어야 한다.
   - 클리어 조건: 과거의 분신이 발판을 밟고 있는 동안 현재 플레이어가 열린 문을 통과하여 출구에 도착하면 성공한다.
   - 실패 조건: 분신의 행동을 잘못 설계해 문을 통과하지 못할 수 있다. 시간 제한이나 별도의 게임 오버는 없으며, R키로 스테이지를 초기화하여 재도전할 수 있다.
5-2. 스테이지 1에 등장하는 것들:
   - 플레이어 → 갖고 있는 정보: 현재 위치, 이동 속도, 이동 방향 / 하는 행동·규칙: 키보드 입력에 따라 이동하며 출구에 도착하면 스테이지 클리어
   - 과거의 분신 → 갖고 있는 정보: 기록된 위치 정보, 재생 시간, 현재 위치 / 하는 행동·규칙: 10초 전 플레이어의 이동 경로를 재현하고 발판을 작동시킬 수 있음
   - 발판 → 갖고 있는 정보: 위치, 활성화 여부 / 하는 행동·규칙: 플레이어나 분신이 올라가 있는 동안 문을 열어 줌
   - 문 → 갖고 있는 정보: 위치, 열림·닫힘 상태 / 하는 행동·규칙: 발판이 활성화되면 열리고 비활성화되면 닫힘
   - 출구 → 갖고 있는 정보: 위치, 도착 여부 / 하는 행동·규칙: 실제 플레이어가 도착하면 스테이지 클리어
   - 벽 → 갖고 있는 정보: 위치, 충돌 범위 / 하는 행동·규칙: 플레이어의 이동을 제한하고 이동 경로를 구성함
   - 시간 시스템 → 갖고 있는 정보: 경과 시간, 10초간 기록된 위치 데이터 / 하는 행동·규칙: 플레이어의 이동을 기록하며 10초마다 새로운 분신으로 교체함
5-3. 입력 방식: 키보드
   - w,a,s,d → 위 왼 밑 오 이동
   - r → 스테이지 초기화, 다시시작
   - esc → 일시정지 및 메뉴 열기
5-4. 화면 시점: 고정 한 화면 | 발판·문·출구와 과거 분신의 움직임을 한눈에 확인하기 쉽고, 첫 스테이지에서 카메라 이동 기능이 필요하지 않기 때문.
6. 더 추가한 것:
   - 게임 이름: PAST ME (10초 전의 나)
   - 스테이지 1 이름: 두 사람의 문 (이전 대화에서 제안된 이름, 확정 여부 미정)
   - 첫 구현 범위: 플레이어 이동 → 위치 기록 → 분신 재생 → 발판 작동 → 문 개방 → 출구 도착
   - 분신 개수: 스테이지 1에서는 기존 분신을 새 분신으로 교체하는 방식 (동시에 여러 분신을 활용하는 기능은 추후 고려)
   - 나중에 할 것: 여러 분신 동시 생성, 움직이는 장애물, 복잡한 스테이지 선택 화면, 저장 및 이어하기 기능 (이전 대화에서 제안, 미확정)
```

## 🤔 ver1 vs ver2 비교 소감
